# SAM2 Zero-Shot Object Tracking

This application uses Meta's Segment Anything Model 2 (SAM 2.1) to track objects from a single source frame to a target frame.

### Features
- Upload source image and mask.
- Track objects in a single target image.
- Zero-shot tracking based on initial frame embedding.
